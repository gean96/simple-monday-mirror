Escolha a empresa abaixo. Em seguida, use o deep link, o envio para o app no PC ou o QR Code para liberar os endpoints no Simple Monday.

Organizações disponíveis

— Configuração da organização selecionada

1. Celular (Android / iOS)

Com o app instalado, toque no botão. O deep link deve reabrir o mesmo Simple Monday que você usou para abrir esta página (não abra outro atalho na tela inicial).

Abrir no app (deep link)

Se falhar, copie o link e use Importar via Link no app.

2. Windows (app já aberto)

Deixe o Simple Monday aberto neste PC e clique abaixo. O browser fala com o listener local em 127.0.0.1:18765 (mesmo padrão do Guardi).

Enviar para o app neste PC

Se o navegador bloquear, confirme a abertura de http://127.0.0.1 — é seguro e só no seu computador.

3. Escanear QR

No app: menu → Escanear QR Code (ou colar o link em Importar via Link).
